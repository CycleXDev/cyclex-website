# CycleX

**On-chain security tools for wallets, tokens and communities.**

CycleX helps users understand blockchain risk through clear, verifiable security signals — without requiring deep technical knowledge.

## Security Tools

- **Token Scanner** — contract risk, holder distribution, liquidity, taxes, ownership and market signals
- **Wallet Security** — approvals and permission analysis
- **CycleX Firewall** — wallet risk visibility and protection tools
- **Telegram Scanner** — instant token security checks directly inside Telegram

## Supported Networks

CycleX supports Solana and multiple EVM networks, combining on-chain and market data into a single security view.
